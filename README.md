# LIGTAS Model

## Description
LIGTAS is a machine learning model for flood water voltage monitoring and safety classification.
It uses a trained Random Forest model to classify voltage readings detected in flood water into
two categories: Safe and Dangerous. It includes both Python training/validation scripts and
C++ headers for embedded deployment on Arduino/ESP32.

## Use Case
Monitors AC voltage leakage from downed power lines or damaged transformers spreading into
flood water. Based on the Electric Shock Drowning (ESD) research by Rifkin & Shafer (2008),
the system estimates the hazard surface area in flood water using the formula:

```
hazard_radius (m)  = V / 6.56
coverage_area (m²) = π × (V / 6.56)²
```

Where 6.56 V/m is the lethal voltage gradient threshold in fresh water (2 V/ft),
as established by the US Coast Guard ESD study.

Reference: https://en.wikipedia.org/wiki/Electric_shock_drowning

## Classification
| Class | Voltage Range | Meaning |
|-------|--------------|---------|
| Safe (0) | 0 – 29.99 V | Below ESD dangerous threshold, or brief spike (1–2 samples) |
| Dangerous (1) | 30 V+ sustained | Exceeds safe exposure limit (3+ consecutive readings) |

> **Spike rejection (v7.0):** A single high voltage reading (1–2 samples at ≥30V) is
> classified as Safe. Only sustained readings are classified as Dangerous.
> The sensor must be read exactly once every **500ms** for temporal features to work correctly.

## Usage

### Training and Validation
1. Open `ligtas_training.ipynb` in Jupyter Notebook
2. Ensure `ligtas_voltage_dataset_v7.csv` is in the same folder
3. Run cells sequentially to train and validate the model
4. Cell 18 exports `ligtas_model.h` for Arduino

### Response Time Chart
1. Fill in `ligtas_response_time_template.xlsx`
2. Run:
   ```bash
   python ligtas_response_time_chart.py
   ```
3. Output: `response_time_chart.png`

### C++ Integration
Add `ligtas_reset()` in `setup()`, then call `ligtas_predict()` once every 500ms:

```cpp
void setup() {
    ligtas_reset();  // initialize temporal state
}

void loop() {
    float acVoltage = readVoltage();  // your ZMPT101B reading
    LigtasResult result = ligtas_predict(acVoltage);

    Serial.println(result.status);          // "Safe" or "Dangerous"
    Serial.println(result.hazardRadius);    // e.g. 4.57 m
    Serial.println(result.coverageAreaStr); // e.g. "65.7 m2 [!]"

    delay(500);  // must match training sampling interval
}
```

## Model Details
- Algorithm: Random Forest (100 trees)
- Classes: 2 — 0=Safe, 1=Dangerous
- Features: 9 engineered features from voltage readings
  - Static (6): voltage_v, voltage_squared, coverage_area_m2, voltage_class, danger_score, sensor_noise_level
  - Temporal (3): dv_dt, rolling_mean_5, consec_above_30
- Accuracy: 96.54% | Precision: 96.54% | Recall: 96.54%
- Sampling rate: 500ms per reading
- Coverage formula: ESD flood water — A = π × (V/6.56)²
